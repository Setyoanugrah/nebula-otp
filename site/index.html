Integrasi 5 menit

Dua request. Tidak ada SDK yang harus dipelajari, tidak ada dependency aneh.

# 1. kirim kode
curl -X POST https://api.nebulaotp.id/v1/otp/send \
  -H "X-API-Key: otp_xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"channel":"email","destination":"user@mail.com"}'

# 2. verifikasi kode yang diketik user
curl -X POST https://api.nebulaotp.id/v1/otp/verify \
  -H "X-API-Key: otp_xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"channel":"email","destination":"user@mail.com","code":"123456"}'

# -> {"ok": true, "verified": true}
